# logitech-audio-enhancements-off
Dette er automatiseringa som slår av Logitech HX2E/Windows-lydforbetringar. Ho slår ikkje direkte av surround-knappen i G HUB, men deaktiverer lydbehandlinga som gjorde at lyden ikkje framstod som rein stereo. Ho køyrer berre ved innlogging – ikkje kvar gong headsettet blir slått av og på.
